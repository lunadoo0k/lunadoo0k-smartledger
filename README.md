## 📝 소개

순수 JavaScript로 만든 웹기반 개인 가계부 애플리케이션입니다.  
현금 중심의 생활을 하는 사람들을 위해 설계되었습니다.

**특징:** AI 기반 로컬 분석, 자산 관리, 고정비 추적, 목표 설정 등

---

## 🎯 주요 기능

### 💰 거래 관리
- 수입/지출 기록 및 카테고리 분류
- 일일/주간/월간 거래 내역 조회

### 📊 통계 분석
- 월별, 주별, 일별 상세 통계
- 카테고리별 지출 분석

### 💳 자산 관리
- 자산 유형 분류 및 추적
- 도넛형 차트로 자산 시각화

### 📅 고정비 관리
- D-day 자동 계산
- 자산별 고정비 관리

### 🤖 AI 로컬 분석
- 인터넷 불필요 (100% 로컬 처리)
- 개인 맞춤 절감 조언

---

## 🚀 사용 방법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 현금 예산 설정
3. 거래 내역 입력 시작

---

## 💾 데이터 관리

- **LocalStorage 사용:** 모든 데이터는 개인 PC의 브라우저에 로컬 저장
- **인터넷 불필요:** 오프라인에서도 완벽하게 작동
- **개인정보 보호:** 서버로 데이터가 전송되지 않음

- Chart.js (도넛 차트)
